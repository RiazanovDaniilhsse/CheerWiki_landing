# CheerWiki — лендинг

Публичная презентационная страница проекта **CheerWiki** — единой базы знаний
и вики-энциклопедии по чир-спорту.

Этап 2 итогового проекта: статический лендинг без бэкенда и бизнес-логики.

## 💡 О проекте

В СНГ нет структурированного источника по правилам и технике элементов
чир-спорта: материалы разбросаны по соцсетям, роликам и тяжёлым PDF-документам.
Это создаёт риски для здоровья спортсменов из-за ошибок в биомеханике стантов
и пирамид.

**CheerWiki** решает это: каталог элементов с фильтрами по уровню и категории,
видеодемонстрациями и разбором техники по ролям — флайер, база.

### Целевая аудитория

- **Спортсмены** — изучают технику своей роли в элементе.
- **Тренеры** — быстро подбирают элементы для занятия прямо на тренировке.

## ✨ Что на лендинге

- **Hero** — название, ценностное предложение, CTA.
- **Проблема** — четыре боли, которые решает продукт.
- **Возможности** — ключевые функции CheerWiki.
- **Сценарии** — как продуктом пользуются спортсмен и тренер.
- **Превью интерфейса** — макеты экранов каталога и карточки элемента.
- **Сравнение** — чем CheerWiki отличается от соцсетей и PDF-регламентов.
- **CTA** — форма подписки на запуск MVP с валидацией email.

## 🛠 Технологии

- **HTML5** — семантическая разметка.
- **CSS3** — Flexbox, Grid, CSS-переменные, адаптив.
- **Vanilla JavaScript** — только валидация формы email, без фреймворков.

## 🚀 Локальный запуск

1. Откройте папку проекта в VS Code.
2. Установите расширение **Live Server**.
3. Правый клик на `index.html` → **Open with Live Server**.
4. Откроется `http://127.0.0.1:5500`.
